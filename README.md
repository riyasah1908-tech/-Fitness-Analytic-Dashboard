A multi-page Fitness & Gym Analytic Dashboard built with Microsoft Power BI to deliver deep visibility into gym operations, financial health, and member wellness.   
Featuring a sleek dark-mode UI with customizable theme switching, this dashboard translates raw member data and gym financials into clear, interactive insights. It also includes a dedicated, interactive health calculator that empowers users to estimate personalized fitness benchmarks in real time.

Home / Landing Page: Clean introductory interface featuring integrated page navigation.
Overall Performance: High-level gym KPIs, financial breakdown, membership tier distribution, and active tracking. 
Calorie & Fitness Calculator: Interactive body metric calculation powered by dynamic What-If parameters.  
Member Insights: Demographic distributions, member goals, and individual retention status

✨ Key Features
1. 💼 Gym Operations & Financial Performance
    Executive KPIs: Real-time visibility into Total Clients (100), Active Trainers (20), Total Revenue (4.1M), and Expenses (1.2M).
    Financial Breakdown: Side-by-side monthly comparisons of Revenue vs. Expenses with a dashed trendline for Net Profit.
    Monthly Member Acquisition: Bar chart visual highlighting peak registration periods with dynamic Max/Min metric toggles.

 2. 🪪 Membership Lifecycle & Tier Tracking
    Tier-Wise Distribution: Donut charts breaking down membership volume across Platinum, Gold, and Silver tiers.
    Status Indicators: Instant segmentation between Active and Expired memberships.
    Progress Visuals: Dynamic SVG progress bar charts tracking completed vs. remaining membership days per client.

  3. 🧮 Interactive Health & Calorie Calculator
     What-If Input Sliders: Dynamic numeric sliders to set Age, Height, Weight, and Activity Level.
     Real-Time BMI Gauge: Dynamic Body Mass Index calculation with automatic category labeling (Underweight / Normal / Overweight)
     Caloric Projections: Automated formulas calculating BMR (Basal Metabolic Rate), TDEE (Total Daily Energy Expenditure), Maintenance Calories, Mild Weight Loss, and Extreme Weight         Loss targets

  4. 👥 Member Demographics & Behavior
     Age & Gender Segmentation: Grouped distributions highlighting member categories across age brackets (18–25, 25–40, 40–60).
     Goal Analysis: Detailed breakdowns tracking specific member targets such as Weight Loss and Muscle Gain.
     Interactive Filtering: Slicers for Gender and Status with single-click table cross-filtering.
